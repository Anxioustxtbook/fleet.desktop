THE DATABASE OF THE .EXE   (v24: SQLite)

The data is kept in SQLite, using the sqlite module built into Electron's Node (nothing to install or compile).
The folder is FIXED, %APPDATA%\FleetPilot (not under the app name), so a changed name or ID cannot make it look empty.

WHAT IS IN %APPDATA%\FleetPilot
  databases\     your database(s), one SQLite file each (<name>.db). Settings chooses which opens at start (default: the last one used).
  copies\        one SQLite monthly archive containing snapshots for every database and month; automatic yearly full-database copies after 12 distinct months with a successful save; and one copy before the data layout is upgraded.
  damaged\       a file that could not be read is moved here, never overwritten; FleetPilot then tries to restore the newest valid monthly archive snapshot or yearly copy.
  old-files\     the .fpdb.json files of v21 and earlier, kept unchanged after their data was moved into SQLite (first start of v23).
  settings.json  which database opens at start and the app-level admin PIN hash.

INSIDE A DATABASE
  meta      format, format version, program version, name, saved at, record count
  fields    every top-level part of the ledger, in order (a list, or a value such as settings)
  records   one row per record: list (vehicles, rentals, payments ...), position, id, the record as JSON
Every save is one transaction: fully written or not at all.
The active database is a continuous ledger across calendar years; January does not create or switch to a new database. Daily information is queried from SQLite by date, with date indexes for rentals, payments, expenses and bookings. Phone sync compares and applies changes against this same active database.

Installing a newer version replaces the program only. An uninstall keeps this folder.
Only one copy of the program can run at a time, so two copies can never write the same database.
SQLite autosaves ledger changes. Excel stays for manual import and export only: File & backup > Save Excel backup / Open Excel backup / Import.
Import Excel is for the original performance workbook; it now blocks FleetPilot-generated backups to prevent report totals being re-imported as new records. For each import, choose Merge into the active database or Replace it. Merge is first previewed without changing the database; Save merge writes it to SQLite, and Undo merge restores the prior ledger until another change is made. Merge adds matching workbook records without duplicating prior imports. Replace removes the existing ledger records, including record types absent from the workbook, and loads the workbook data; before it does so, FleetPilot creates a separate database snapshot of the latest saved ledger. Use Open Excel backup to restore a FleetPilot export.
Settings is the database manager: create a database, open one, choose the startup default, or delete an inactive database. It remains behind the app-level admin PIN, stored separately from SQLite and shared across databases. The Forgot PIN action uses the configured recovery code without displaying it. The database in use cannot be deleted.
Connect phone pairs a phone and synchronizes its changes with the active SQLite database over the trusted local network.
Recover an earlier copy lists database safety snapshots and lets you refresh the current month's full-database snapshot manually. The current month's snapshot is refreshed in the same `FleetPilot monthly backups.db` archive after every successful save. FleetPilot makes a separate full-database yearly copy after 12 distinct calendar months have each had a successful SQLite save. At startup, a missing or damaged active SQLite database is set aside when possible and restored from the newest valid monthly archive snapshot, then a yearly copy. Reset asks for confirmation and clears the active database without creating another snapshot; records on a synced phone are not cleared and may return during a later sync. Delete snapshot asks for confirmation and removes only that snapshot; it does not delete the active database. Snapshot recovery restores into the existing database and never creates another database.
The branded welcome splash is displayed for three seconds as the app starts. The Today overview is shown at most once per calendar day, including across app restarts.
To back up by hand: close FleetPilot and copy the .db file.
